    Zotero: Reference Management for Digital Scholarship

    Zotero is the primary reference management solution for the AMS Digital Scholar (DS) programme. It is an open-source, community-driven tool designed to collect, organise, cite, and share research sources. For AMS, it serves as a centralised "Digital Library" for managing both academic journals and the high volume of grey literature (site reports, EIARs, and client briefings) characteristic of our industry.

    Why Zotero for AMS?

    • Grey Literature Management: Unlike other tools, Zotero excels at handling unpublished archaeological reports, allowing for manual metadata entry (Site Codes, Townlands, and County data).
    • Collaborative Power: Group Libraries enable teams to sync references and annotated PDFs across multiple users and devices, ensuring everyone on a project is using the same source of truth.
    • Seamless Integration: Works directly with Microsoft Word (for formal reports), Google Docs (for collaborative drafting), and modern digital tools like Obsidian and MkDocs.

    Key Collaborative Features

    1. Group Libraries

    AMS project teams can create Private Group Libraries. These are shared spaces where all members can see the same collection of papers, notes, and PDF files. * Action: Project Leads should create the group and invite team members as 'Admins' or 'Members'.

    2. Collaborative PDF Annotation

    Since Zotero 6, the built-in PDF reader allows for team-based highlighting and commenting. * Note: Annotations are synced to the group database, identifying which team member made a specific observation. This is ideal for peer-reviewing archaeological assessments.

    3. The "Inbox" Workflow

    To maintain a high-quality library, AMS recommends the Inbox method: * New sources are dropped into an _INBOX collection. * The Project Lead or a designated 'Librarian' reviews the metadata (ensuring the author, year, and site title are correct) before moving the item to the permanent project folder.

    Best Practices for Archaeological Data

    • Standardised Tagging: Use a unified tagging system for Site IDs, Periods (e.g., Mesolithic, Medieval), and Material Types (Lithics, Ceramics).
    • CRAV Protocol: Always apply the Check, Review, Approve, Verify protocol to imported metadata. Automated imports from web browsers often miss Site Codes or specific Irish/UK townland spellings.
    • Company Ownership: Group Libraries should be 'owned' by a generic AMS Research account (e.g., ai@ams-archaeology.com) rather than an individual staff member, ensuring continuity if personnel changes.

    Advanced Integration

    Better BibTeX (BBT)

    For technical reporting using Markdown or LaTeX, the Better BibTeX plugin is essential. It generates stable citation keys (e.g., Brayne2024SiteX) that remain consistent across the entire team.

    Zotero Connector

    Install the browser extension to save reports directly from national heritage databases like the National Monuments Service (NMS) or the Heritage Gateway.

    Setup Guide for AMS Staff

    1. Download: Install Zotero from zotero.org.
    2. Account: Register using your AMS email address.
    3. Groups: Check your email for invitations to AMS Project Groups.
    4. Browser: Install the Zotero Connector for Chrome or Edge.

    For further assistance or to request a new Group Library, please contact the AI Strategy team.
