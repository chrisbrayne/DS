# Managing Archaeological Imagery with Tropy

Tropy is the essential tool for organising and describing large collections of digital photos. This tutorial explains how to apply the AMS Metadata Standard to your site photography.

## 1. Installation & Project Setup
1.  **Download:** Install Tropy from [tropy.org](https://tropy.org/).
2.  **New Project:** Open Tropy and select **File** -> **New Project**. Save it as `SiteCode_Photography_Project`.
3.  **Importing Photos:** Drag and drop your site photos directly into the Tropy window.

## 2. Applying the AMS Metadata Standard
AMS uses a specific metadata schema to ensure compatibility with national archives.
1.  Go to **Settings** -> **Templates**.
2.  Import the `AMS_Archaeology_Template.ttp` (available in the `research/` folder).
3.  Select an image and apply the template from the metadata pane on the right.

## 3. Bulk Editing
To save time, you can apply metadata to multiple photos at once:
1.  Select multiple photos in the item view.
2.  Update a field (e.g., **Site Code** or **Photographer**) in the metadata pane.
3.  The change will be applied to all selected items.

## 4. Exporting for Reports
Once your photos are described, you can export the data for use in the **AMS Document Factory**:
1.  Select the items you wish to export.
2.  Go to **File** -> **Export**.
3.  Choose **CSV** to generate a photo register that can be inserted into your Word report.
