# Building an Archaeological Knowledge Graph in Obsidian

This tutorial guides AMS staff through setting up a "Knowledge Graph" for archaeological research using Obsidian. By the end of this guide, you will have a structured vault that links sites, periods, and legislation.

## 1. Why use Obsidian?
Archaeology is non-linear. Obsidian allows you to connect disparate pieces of evidence (e.g., a specific lithic scatter linked to a post-glacial climate event) using `[[Wikilinks]]`. This creates a searchable, networked database of your research.

## 2. Setting Up Your Vault
1.  **Download & Install:** Get Obsidian from [obsidian.md](https://obsidian.md/).
2.  **Create a Vault:** Choose a folder on your project-specific OneDrive or AMS server. Name it "AMS_Digital_Scholar_Vault".
3.  **Core Settings:**
    *   Go to **Settings** -> **Files & Links**.
    *   Enable **"Automatically update internal links"**.
    *   Set **"Default location for new attachments"** to a specific folder (e.g., `_attachments`).

## 3. Creating Your First Site Note
Create a new note named after your Site ID (e.g., `A056_Tara_Meath`). Use the following structure:

```markdown
# Site: A056 - Tara, Meath

## Metadata
*   **Site Code:** A056
*   **Period:** [[Iron Age]], [[Medieval]]
*   **County:** [[Meath]]
*   **Legislation:** [[National Monuments Act 1930]]

## Summary
Brief description of the site and findings.

## Related Research
*   Linked to [[Comparative_Site_B]]
*   See annotations in [[Zotero_Notes_A056]]
```

## 4. Visualising the Graph
Click the **Graph View** icon on the left sidebar. As you add more notes and links, you will see a visual representation of how your research is connected.
