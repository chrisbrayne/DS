# Obsidian: Knowledge Management & Networked Thought

Obsidian is the primary "Knowledge Graph" tool for the **AMS Digital Scholar (DS)** programme. It is a powerful Markdown-based application that allows researchers to link notes, creating a "Second Brain" for complex archaeological projects. For AMS, it bridges the gap between raw site data and the final narrative in our reports.

## Why Obsidian for AMS?

*   **Non-Linear Research:** Archaeology is rarely linear. Obsidian allows us to link a **Site ID** to a **Period**, a **Find Type**, or a **Historical Figure** using `[[Wikilinks]]`.
*   **Local & Secure:** Unlike cloud-based tools, Obsidian stores files locally on AMS servers as plain Markdown (`.md`). This ensures long-term data preservation and client confidentiality.
*   **Automated Registers:** Using the **Dataview** plugin, we can automatically generate lists of contexts, finds, or stratigraphic units directly from our field notes.

## Key Workflows for Archaeologists

### 1. The "Second Brain" for Sites
Create a master note for every major excavation or consultancy project. Use links to connect the site to:
*   `[[Relevant Legislation]]` (e.g., National Monuments Acts).
*   `[[Geographical Context]]` (Townlands, Counties, River catchments).
*   `[[Comparative Sites]]` (Earlier excavations in the same region).

### 2. Strategic Narrative Development
Use Obsidian to draft the "Discussion" sections of **Desk-Based Assessments (DBAs)**. By linking disparate pieces of evidence (e.g., a specific lithic scatter linked to a post-glacial climate event), the AI can help synthesise these connections into a professional narrative.

### 3. Zotero Integration
Use the **Zotero Integration** plugin to import your citations and annotations directly into Obsidian. This creates a searchable database of every paper or report the AMS team has ever read.

## Recommended Plugins for AMS
*   **Dataview:** To create dynamic tables and lists of site data.
*   **Templater:** To ensure every site note follows the AMS standard structure.
*   **Canvas:** For visual brainstorming and mapping out stratigraphic relationships or site phasing.

## Setup Guide for AMS Staff
1.  **Download:** Install Obsidian from [obsidian.md](https://obsidian.md/).
2.  **Vault:** Create a new "Vault" on your project-specific OneDrive or server folder.
3.  **Core Settings:** Enable "Files & Links" -> "Automatically update internal links."
4.  **Community Plugins:** Browse and install *Dataview* and *Zotero Integration*.
